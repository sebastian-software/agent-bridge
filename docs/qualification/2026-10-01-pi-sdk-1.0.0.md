## Supply-chain note

Pi SDK 1.0.0 was published about two hours before adoption. The repository's
pnpm policy requires a 24-hour release age, so `pnpm-workspace.yaml` carries an
explicit exclusion for the eight `@earendil-works` packages at exactly 1.0.0, at
the owner's request. The exclusion can be removed once those versions are older
than 24 hours.

## Passed evidence

- **Tool task.** `write`, `read`, `write`, and `bash` ran sequentially in about
  17 seconds; `probe.txt` contained `after`, the assertion passed independently,
  and git observation was complete.
- **Steering.** An instruction sent during a 20-second `bash` call was accepted
  and delivered with a native acknowledgement in the same second. The command
  finished uninterrupted, and the model then wrote `note.txt` with exactly
  `steered`.
- **Continuation.** A continuation without tools recalled the earlier command
  and the steered file in about 3.5 seconds, linked through `continuedFrom`.
- **Cancellation during a tool call.** The invocation ended `cancelled`, and the
  `bash` process and its `sleep` child were gone.
- **Timeout.** A 45-second timeout ended `timed_out` with no descendant process.
- **Cancellation during generation.** Partial text was kept, and the Ollama log
  recorded `stop: cancel task`.

The deterministic suite (181 tests, including all Pi worker, steering,
continuation, and configuration-guard tests) passed against 1.0.0 without
changes beyond the version pin.
